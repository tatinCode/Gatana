# Gatana
Game Development is one of countless interdisciplinary undertakings that involve several moving parts. Coordinating various divisions of labor to meet a specific milestone can be extremely difficult without a single source of truth to keep large teams in the loop with their design goals. This is where Gatana comes into play by providing the team with two relational databases that synchronize a living design document with a board of concrete tasks assigned to teammates.

## How to run

1. Clone the repo.

2. Navigate into the frontend folder
      ```
      cd Gatana/frontend
      ```
      
3. run:
      ```
      npm install
      npm run dev
      ```
